# 中国大学 2026 调研

中国大陆高等教育机构与招生规模调研网站。

## 当前口径

- 学校数量：教育部《全国高等学校名单》，截至 2025-06-20。
- 人数规模：教育部《2024年全国教育事业发展统计公报》和 2024 教育统计数据。
- 地域分布：31 个大陆省级单位，不含港澳台。
- 2026 招生：先建立省级跟踪表，招生计划和录取结果发布后持续补齐。

## 本地运行

```bash
npm install
npm run data:build
npm run dev
```

## 验证

```bash
npm test
npm run build
```

## 部署

当前仓库使用 `gh-pages` 分支部署 GitHub Pages；`main` 分支保留源码和数据生成脚本。

## 数据来源

- 教育部《2024年全国教育事业发展统计公报》
- 教育部《全国高等学校名单》
- 教育部 2024 年教育统计数据
- 教育部《关于做好2026年普通高校招生工作的通知》
